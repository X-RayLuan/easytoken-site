How it works

          
From key to first video in three calls.

        

        
Media jobs run asynchronously, so a long Veo render never ties up your server.

      

      

        
Step 1
Create a key
Sign up, claim your free credits, and copy one key that works for every model.

        
Step 2
Send a task
POST to /v1/tasks with a model and its input. Switching models means changing one string.

        
Step 3
Get the result
We call your callback_url when the file is ready, or you poll /v1/tasks/{id}.

FAQ

        
Questions before you switch.

      

      

        
Are these the official models?
EasyToken sends supported media tasks to an upstream service for processing. See the model catalog for supported IDs and options; vendor affiliation and host authorization are not independently verified.

        
What is the “Official / Fal price” you compare against?
It is the price kie.ai/pricing lists for the same model and option in its “Official / Fal Price” column. Savings are shown vs. official / fal price, as listed by Kie, not vs. each vendor's own API, which can be lower. Where Kie lists no price we show “–” and no saving. You see the exact cost before each task runs.

        
What happens when a task fails?
Failed, timed-out and safety-filtered tasks are refunded to your balance automatically. You don't need to file a ticket.

        
Does EasyToken offer chat or text models?
No. This API supports video, image and audio generation, not chat completions or text models.

        
Do credits expire?
No. Prepaid credits stay on your account until you use them.

        
Are there rate limits?
Concurrency limits apply per model. See the API response for rate-limit errors; custom limits require confirmation.

        
Can I get an invoice for my company?
Billing settings accept company name and VAT number. Confirm invoice availability and tax treatment before relying on them.
