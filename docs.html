EasyToken video, image and audio API documentation

Media models only. Chat and text models are not offered.

Quickstart

The API lives at https://api.easytoken.si/v1. Every model uses the same key. Video, image and audio models run as tasks: you create one, then receive the result by webhook or by polling.

  1. Create an account and copy your API key from the dashboard.
  2. Send your first task with the request below.
  3. Open the result.url when the task finishes.
first-task.sh
curl https://api.easytoken.si/v1/tasks \
  -H "Authorization: Bearer $EASYTOKEN_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.5",
    "input": { "prompt": "Product spin on a marble table" }
  }'

Authentication

Send your key as a bearer token in the Authorization header. Keys start with et_live_. Keep them on your server; never ship them in a browser or mobile app.

You can create several keys, each with its own daily spend cap, from Dashboard → API keys.

Media tasks

POST /v1/tasks creates a video, image or audio job and returns at once with a task ID.

FieldTypeDescription
modelstringModel ID, e.g. veo-3.1. See Model IDs.
inputobjectModel-specific input. Inputs vary by model; consult the catalog and validate a request with POST /v1/quote before creating a task. Video and image models accept aspect_ratio and image_urls (https links) for image-to-video or editing. Price-setting options are resolution (e.g. 720p, 1080p, 4k; images 1K/2K/4K), duration in seconds, mode (Veo quality/fast/lite, Kling 3.0 std/pro/4K, Hailuo standard/pro, Imagen fast/standard/ultra) and audio (sound or generate_audio). Suno accepts style, lyrics, title and instrumental. Unsupported options can return 422 before a task is charged; check the quote and task response: e.g. Veo 3.1 is 8s only, Wan 2.6 takes 1 input image, Grok Imagine Video takes up to 7 images (1 at 1080p).
callback_urlstringOptional public https URL. We POST the finished task here.
metadataobjectOptional. Returned unchanged, useful for your own IDs.

Get a task

GET /v1/tasks/{id} returns the current state. Copy output files you want to keep; retention terms require owner confirmation. status moves through queued → running → succeeded or failed. Poll every 5 to 10 seconds, or use a webhook instead.

succeeded
{
  "id": "task_8f2kq1x",
  "status": "succeeded",
  "result": { "url": "https://…/output.mp4", "urls": ["https://…/output.mp4"], "type": "video" },
  "cost_usd": 1.81125
}

Webhooks

When you pass callback_url, we send the same body as Get a task once the task finishes. Each request carries an X-EasyToken-Signature header: an HMAC-SHA256 of the raw body with your webhook secret. Reply with any 2xx within 10 seconds; we retry up to 5 times with backoff.

Rate limits

New accounts can run 10 media tasks at once per model. For higher limits, request confirmation from support.

Billing

Usage is paid from prepaid credits. Each task's price depends on the options you pick, is fixed when it is created and shown in cost_usd. To see a price first, POST /v1/quote with the same model and input as a task (no key needed, nothing is charged). A task reserves credits on creation. When a task reaches a failed state, the Worker returns its reserved cost to the balance and records the task cost as zero. Confirm task status when checking a refund; a successful task remains charged.
